# 输入法占位保护 · 0.4研究预览

这是实际修改原生容器宽度的预览工具，不是只读采集器，也不是稳定版安装包。
不要覆盖现有WindowMark.exe；三个EXE/DLL必须放在一起。

## 使用

双击`WindowMarkImeTrayGuard.exe`，默认关闭，点击“启用保护（预览）”。
先切到本地文本窗口，让原生输入法图标显示，等状态为“保护生效”后切换远程窗口。
图标消失时保留空位，不补画、不增加托盘图标，不依赖WindowMark图标是否折叠。
点击“恢复系统默认”或关闭窗口后恢复；可以最小化，关闭后不继续保护，没有开机自启。

仅实测Windows 11 **26300.9711 x64、100% DPI单屏**：32+44px原生按钮显隐时，
其余11个托盘按钮坐标不变；关闭后恢复系统默认位移。其它构建（包括Win10）明确拒绝启用。

## 风险和限制

首次启用会加载自写XAML诊断DLL到Explorer。早期重复附加发生过Explorer崩溃，
直接原因是系统全根重放的GetRuntimeElement FailFast。当前改为单订阅/租约复用，
本机未再崩溃，但首次附加的全部触发条件尚未排除，**仍可能影响Explorer，不能保证稳定**。
不要在重要文件复制或桌面操作期间开始首次实验。工具不主动重启Explorer或输入法。

关闭保护恢复原始MinWidth的unset、数值或绑定；诊断连接/DLL留在Explorer直至自然退出，
不强行卸载。界面心跳失联或进程退出会停止续租；控制程序卡住时目标端约5秒期限到期恢复。
初次附加有30秒期限；目标UI线程本身阻塞时，不能承诺即时恢复。
单次连续运行上限24小时，到期恢复并需手动启用；Explorer重启后不自动反复附加。

异常时停止本轮，不连续点击启用。先确认Windows是否自行恢复桌面，不修改输入法全局设置。
诊断日志位于`%LOCALAPPDATA%/WindowMark/ImeTrayGuardPreview/`，不记录输入文字或剪贴板。

原生菜单/空白命中、单图标显隐、100次切换、VNC/MobaXterm、DPI/多屏、第三方冲突、
Explorer重建、Win10及8小时耐久尚未全部验收。未接入WindowMark正式配置/主面板/安装器。
这不是完整需求完成或稳定发布声明。
