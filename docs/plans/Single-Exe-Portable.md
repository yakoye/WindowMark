# 单 EXE 绿色版交付计划

## 已确定的行为

- GitHub 用户附件仅提供 `WindowMark.exe`，源代码仓库保留文档、测试及开发工具。
- 配置固定为 EXE 同目录的 `settings.conf`，用户数据、日志、必要组件缓存均留在该目录下。
- 原生输入法保护 DLL 与独立工具嵌入资源，运行时自动释放到内部缓存。单文件交付不等于运行期间永远只产生一个文件。
- 不需要 portable.on，不按 EXE 名称决定配置位置，不静默改写到 AppData。
- 目录不可写时明确提示并停止启动，不假装保存成功。
- 不删除旧配置或其他用户文件；升级迁移必须明确区分旧数据来源。
- 候选版和正式版都必须按项目和完整版本号双目录归档并核对 SHA-256，候选目录保留 rc 后缀。
