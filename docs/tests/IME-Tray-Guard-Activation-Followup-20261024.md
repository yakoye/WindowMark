# 输入法占位保护：点击失效与首次附加后续排查

用户反馈：安装后图标仍移动，点击「输入法占位保护」无效。Windows 10 暂停，当前只处理本机 Windows 11；未经授权不公开发布。

## 当前证据

- 本轮开始，安装版 PID 26296，父进程为常驻 Explorer 38696；原生控制程序未运行，异常标记不存在。
- 上轮结束时主动恢复为关闭；不能把之前启用期间的几何通过，解释为当前关闭状态也能保护。
- 用户授权本次面板截图后，真实鼠标点击 rc.1 的复选框，发现确实创建了无 owner 的独立确认框，原面板仍显示关闭；不能据此断言所有点击失败均由此产生。
- rc.2 真实鼠标点击后，确认框成为面板的子对话框，面板禁用，焦点进入确认框。确认后显示等待，随后原生状态进入 Reserved，面板显示 140 DIP 生效；恢复后显示已确认恢复。
- 既有首次崩溃栈在 XAML 的全根回放中，尚未写入宽度。复用订阅只能降低重复触发，不能消除首次全根回放风险。

## 局部根研究与失败证据

- `direct-root-01`：公开 GetUiLayer 仅返回 1×1 空诊断 Grid，不能作为任务栏根。
- `direct-root-02`：首次测试启动夹具后未等待就绪，端点全为 NOT_FOUND；保留原失败，不记作产品通过。
- `direct-root-03`：等待夹具就绪后，精确加载映像校验和局部根读取成功，读到 WindowMarkImeSlots 76 DIP；双 UI 线程宿主正常退出，没有全局订阅。
- `direct-root-native-01`：原生任务栏局部根读取到 NonActivatableStack 140 DIP；零写入、Explorer PID 38696 未变化。研究探针因其它根无 Content 报失败，不能把该次退出码写成通过。后续功能实现忽略没有 Content 的非目标根。
- `local-roots-width-01`：双 UI 线程、动态树、副线程退出、三次占位/恢复，最终 writes=3、restores=3、errors=0、subscription_active=0，两个进程均正常退出。

路径移除证据：功能 DLL 不再实现视觉树回调，不调用 Advise/Unadvise 或 GetRuntimeElement。以当前 UI 线程布局根构建临时树，只读取类型、结构和几何，不读取应用文本。限定 PDB GUID `E15A88ED9599B347A0D2576C13287FC4`、age 1、映像大小 `0x1121000` 和入口字节；RVA 由对应微软 PDB 核对。磁盘文件版本显示存在差异，未使用文件版本字符串推算地址。

私有 ABI 限定与剩余风险见集成文档；本报告不宣称跨版本稳定或长期验收完成。

## 回归与原生验证（安装前）

- `local-roots-lease-01`：持续租约跨过 30 秒、界面心跳停止、界面进程被结束三项全部通过，均 1 次写入、1 次恢复、0 恢复失败。
- 52 项 Python 测试通过，CTest 核心和自启动两项通过；构建使用 `/W4 /WX`，无编译警告和错误。
- `local-roots-native-01`：新 DLL 首次连接成功，Reserved=140 DIP，`subscription_active=0`；haps03 隐藏两个按钮、总宽度减少 76px，24 个既有锚点（含小三角、Everything、开始及应用按钮）全部无位移。最终采集及恢复结果在安装核验记录补充。
- 上述测试均未主动重启 Explorer、输入法，也未改变全局输入法设置。旧版已加载的 DLL 未强卸载；新路径在当前 Explorer 的首次调用通过不等于已覆盖全新 Explorer 进程启动。

安装前 90 秒原生租约最终退出 0：state=Closed、writes=1、restores=1、restore_failures=0、errors=0。
100 个几何样本包含一次 76px 隐藏事件，24 个锚点不变、覆盖完整。不能将一次事件等同于 100 次切换或逐帧验证。
