## 发现并修复的问题（保留失败，不覆盖为通过）

1. 初次编译：`UIAutomationCore.h` 类型声明报 C4430，后续大量级联错误。
   原因：WIN32_LEAN_AND_MEAN 下 UIAutomation.h 前未包含 COM 定义。补 `ole2.h` 后重新编译成功。
2. 初版工具未带系统兼容性 manifest：Explorer 固定文件版本读成 6.2 开头。
   加 manifest 后读得 10.0；旧样本不用于平台兼容性判断。
3. 初版会记录应用任务按钮的 AutomationId（可能含路径）。调整为读取 ID 前跳过 TaskList 节点。
   其它托盘原始名称不保存，只保存固定 IME 类别词。
4. 启动器初测失败：PS5.1 子进程退出码可能为空，提前持有进程句柄并拒绝空退出码当成功。
5. 启动器第二次失败：继承的模块环境下 `Get-FileHash` 不可用，导致 finally 无运行记录。
   启动器哈希改用 .NET SHA256，不依赖该命令；重跑真实/异常/挂起三条路径全部通过。
   原始失败目录保留，未将其失败结果删除或改写为通过。
