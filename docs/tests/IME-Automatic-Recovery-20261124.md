# 输入法占位旧标记与异常退出自动恢复

## 问题与行为

先前版本遇到同一个仍存活 Explorer 的未确认标记时永久暂停，需要用户关闭再开启。正常保留开启设置无法解决这一运行状态阻塞。

本次加入 --reuse-only 控制模式：有标记的自动恢复只请求既有端点接回租约。没有端点时直接返回，不创建 NativeOnce、不加载新的诊断 DLL、不调用首次附加入口。已有端点只有旧租约已释放、恢复成功时才原子接受 WM_COPYDATA；忙碌时拒绝，不抢占活动会话。兼容 7.100 正在使用的旧 LocalRoots07 端点，不需要替换已加载 DLL 或重启 Explorer。

暂时失败按 5、15、30 秒退避，只在端点自身确认可用时恢复。明确的恢复失败不盲目重试。手动关闭取消等待；设置始终与运行状态分开。进程内重试共用组件副本，避免不断复制 EXE/DLL 占用磁盘。托盘父级只在实际保护生效时打勾，未生效明确标记；子项保留自动恢复偏好。
