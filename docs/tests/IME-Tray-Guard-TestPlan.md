# 输入法占位保护：测试与验收计划

更新：2026-10-24。执行状态见 [真实测试报告](IME-Tray-Guard-Report.md)。
总开发清单见 [实施计划](../features/IME-Tray-Guard-Plan.md)。

## 分层与通过口径

1. 工具测试：参数校验、证据不覆盖、JSON 正确、隐私字段、启动/超时/退出码。
2. 分析器测试：一像素移动、节点消失、身份歧义、环境变化、坏/空/截断样本，不得误判稳定。
3. 原始行为采证：用户在本地控制台操作，关联前台 EXE、实际图标显隐及控件边界；与 RDP 服务端采样分开。
4. 布局原型验证：关/开/关对照，保持显示配置和其余托盘图标集合一致；证明原生功能与恢复。
5. 产品回归与耐久：现有功能、退出异常、更新兼容、多屏和八小时运行。

单元测试和进程退出 0 都不是 P0 功能验收。工具没有写入保护代码，因此当前所有功能用例仍未执行。
坐标验收以同一会话/Explorer 实例/显示器/DPI 下同一真实图标身份为准；不能以枚举顺序配对。
必须先人工确认 IME 目标及非 IME 对照图标。树截断、读取失败、身份缺失记录为不确定。
约每秒一次诊断采样只能证明所采时点，无法排除中间帧跳动；正式验收要追加事件/逐帧边界证据，
并由用户提供需要的视觉录屏/截图，不自动抢焦点截图。

## 当前自动化

- `tools/ime-tray-guard/test_analyze.py`：15 项分析器测试（含参数化子场景）。
- `tools/ime-tray-guard/test_probe.py`：6 项 EXE 测试，真实采集要求当前会话存在可读任务栏。
- `tools/ime-tray-guard/test_transitions.py`：9项相邻转换测试，包含95px位移、身份重建、环境切换、多任务栏隔离。
- `WindowMarkXamlSlotLab`：18项自身进程XAML布局断言，不是原生任务栏占位验收。
- `tools/ime-tray-guard/test-launcher.ps1`：真实采集、夹具退出 7、夹具挂起后返回 124；确认子进程不残留。
- 所有 BAT ASCII；EXE 静态 CRT、系统 DLL 依赖检查；打包与共享逐文件 SHA-256。
- 产品核心测试重新构建运行；不把该项说成完整产品 UI 回归。
- `test_tsf_trial.py`：8项测试，覆盖显式启动、参数边界、不覆盖证据、透明/禁用接口自检、
  正常移除、提前停止与重复实例拒绝。运行时设置`IME_TSF_TRIAL_EXE`，未设置会跳过，不计为实际通过。
- `test-tsf-launcher.ps1`：实验子程序/只读采集器分别报错时，不误报成功，退出码不丢失，无本次子进程残留。
- TSF实验包实际运行验证双进程采集与日志；注册成功、图标回调、项目计数不作为视觉成功判据。

## 对端支持

第一轮控制台采集和截图已收到，不需要重复；仍缺Windows 10样本。
后续若需运行真实视觉树原型，必须另行说明进程内附加与外部UIA采集的区别，不覆盖旧测试包。
若只提供 Win11，不把 Win10 自动标为通过。确认结构后再安排布局原型的启用/关闭验收。

新增TSF实验包与旧只读包分开存放，按`TSF-README.md`执行：10秒基线、45秒临时注册、移除后继续采样。
对端核对实际空槽/宽度/显隐、WindowMark图标折叠状态以及移除后原生点击与输入法状态。
本轮不是自动互补算法验收，也未测试强制终止、Explorer重启、多屏或八小时耐久。

## 发布门槛

### 2026-10-24新增安全门槛

历史0.3阶段：真实Explorer附加在宽度写入前崩溃，停止真机附加，0.3包只允许自建夹具。
不因修正了COM封送或隔离测试通过就恢复真实入口。

- `test_container_trial.py`：5项门禁测试；必须设置`IME_CONTAINER_TRIAL_EXE`实际执行，不能把跳过当通过。
- `WindowMarkXamlSlotLab`：29项布局/事务检查，覆盖原始unset、数值、绑定及非法参数拒绝。
- `test-container-owner-exit.ps1 -NormalExit`：内容隐藏期间保留76 DIP；退出后原始0/unset恢复；内容回来后76 DIP。
- 同脚本不带NormalExit：只终止自身控制程序，检查宿主独立恢复，不能终止Explorer模拟。
- 最终包通过`run-container-lab.ps1`串联上述测试；不要求用户为隔离实验切换窗口。
- 正式恢复真机研究前，先取得附加异常根因与安全生命周期证据。保留原生IME-001～018未验证状态。

0.4阶段：精确符号定位直接FailFast；单订阅复用后，经用户授权的本机原生占位与恢复已测有效。
`test-client-lease.py`串行执行40秒续租、界面停止心跳和界面被结束；真实目标仅自身夹具。
原生中文界面只验证了短时haps03往返和恢复按钮，不代替表内100次、菜单/命中、多屏和Win10验收。
对端TSF已确定未占位，不再重复；新原生预览须明确风险，自愿验证，不能称为只读工具。

所有承诺支持的配置 P0 实测通过；恢复与异常项通过；未知版本不修改；现有功能无回归；
测试报告完整可复核。任一缺失都只能交付实验包，不增加正式版功能宣传或发布标签。
