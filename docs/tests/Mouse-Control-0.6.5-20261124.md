# 0.6.5 鼠标控制验收

## 实现与自动测试

- Release 构建通过，使用 /W4 /WX。
- CTest 3/3：原核心测试、启动项测试、新增鼠标测试均通过。
- 节流检查覆盖首次放行、阈值前后、上下反向独立、水平独立、零输入、不同 delta、50/80/100 毫秒以及 1000Hz 持续输入每秒恰好放行 20 次。
- 配置检查覆盖两个开关默认关闭、分别启用、保存重读、非法数值与边界钳制。
- 原生接口测试仅将指针速度设为当前值，不移动鼠标、不发送滚轮事件；验证保存与删除恢复记录、启动恢复、外部速度变化不覆盖、损坏记录拒绝恢复。
- 实际安装及卸载滚轮监听，确认启用状态变化；未通过自动滚动用户应用来冒充设备链路验收。
- 单 EXE 验收脚本 14 项通过：内置组件、同目录配置、缓存修复、中文空格路径、搬迁与不回落 AppData。
