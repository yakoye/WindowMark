# 输入法占位保护 rc.3 测试记录

日期：2026-10-25。版本：0.6.1-rc.3。仅本地开放测试，未发布。

## 变更与验收清单

- [x] 移除 100% DPI、单显示器、Windows 补丁号的启用门禁。
- [x] 保留所加载系统映像身份及内部入口校验，不调用未知地址；Windows 10 暂停开发。
- [x] 主任务栏布局变化先恢复原值，稳定两秒后重新学习；解锁、会话重连和唤醒后恢复一次。
- [x] 手动关闭取消待恢复任务；恢复失败或 Explorer 重建停止，不循环附加。
- [x] 主面板、托盘和配置接入提示语开关，默认开启提示语；保护功能整体默认关闭。
- [x] 输入法隐藏且占位生效时显示短句，原生图标恢复时隐藏，不拦截点击。
- [x] 自建 XAML 宿主验证显隐、透明模式、移除文字、恢复布局及恢复任务取消。
- [ ] 高 DPI、多显示器实机覆盖：已开放用户测试，本轮未改变系统缩放或显示器设置。
- [ ] 长时间稳定性：尚未完成八小时验收。

## 已执行测试

主工程 Release 构建通过；核心 CTest 2/2、相关 Python 测试 52/52 通过。
首轮 `build/ime-tray-guard/evidence/rc3-fixture-01/summary.json` 中三种模式全部通过；修复隐藏期间重开文字后的复测 `rc3-fixture-02` 四种模式全部通过：

1. 提示语模式：隐藏期间槽位宽 76、文字不接收点击、原生内容恢复时隐藏；正常退出后文字移除且 MinWidth 恢复未设置状态。
2. 透明模式：不插入提示语对象，仍正确固定及恢复宽度。
3. 恢复模式：布局变化自动恢复、锁定期间暂停且解锁恢复、手动关闭取消重连均通过。事件只发到自建测试窗口，未锁定用户桌面。
4. 动态文字开关：内容隐藏期间关闭文字、再次开启立即显示，不必等待原生图标重新出现。

`rc3-client-lease-01` 中正常退出、心跳失联和界面进程死亡三种模式通过，均写入一次、恢复一次、恢复失败零次。

本机原生测试证据：`build/ime-tray-guard/evidence/rc3-native-01`。
在已打开的 haps03 与本地 Everything 之间切换前台，不操作远程内容、不截图。
新局部根筛选能够找到主任务栏，保留宽度为 140 DIP；原生输入法隐藏时提示语起点 64、宽 76，恢复后隐藏。
原生租约结束记录 state=5、writes=1、restores=1、errors=0、restore_failures=0。
首轮几何采样保留了未通过结果：三个识别到的转换中，两次全部锚点不变；另一次应用按钮数量由 22 个总锚点减至 21 个、应用区发生 22px 位移，整组 `geometry_passed=false`。不可丢弃该结果或称整组通过；安装版另行采样核对。

提示语每 45 秒轮换「加油鸭」「喝杯水」「歇一会」「眨眨眼」「慢慢来」「伸个懒腰」，使用主题适配的普通 XAML 文字。关闭提示语只移除自有文字，保持透明占位；关闭保护恢复布局。

旧 rc.2 长观测因升级中止：647 个样本、3258.41 秒，未出现 inactive/error 样本。这不是八小时通过证据。

## 本机安装核验

安装程序退出码 0；安装文件版本及产品版本均为 0.6.1-rc.3。六个二进制文件与本次 Release 产物 SHA-256 一致。
通过常驻 Explorer 启动：主程序 PID 31660，父进程/任务栏 Explorer PID 38696；Explorer 仍为 2026-10-24 19:27:46 启动的实例，没有为升级重启。
面板文字树显示新版标题、提示语开关及「原生占位保护已生效：140 DIP」。
只读控制共享协议确认 state=3、stop=0、width=140、show_hints=true、restore_failures=0。证据在 `rc3-installed-01/client-final.json`，没有通过写共享内存修改开关。

桌面工具的远程窗口激活受到“用户正在操作”保护限制；面板鼠标测试返回 `coordinate input geometry is unavailable`。本次没有绕过这些限制，没有自动截取任务栏或远程桌面。键盘调用返回成功但文字树不提供复选框值，故不将它记为完整鼠标点击验收。最终开启状态用只读协议另行确认。
安装后采集的 160 份几何样本没有识别到 IME 显隐事件，检测器正确返回 `geometry_passed=false`，不能用这些静态样本代替显隐验收。首轮原生 haps03 显隐及夹具四组证据独立保留。

## 边界

本机验证不代表全部 Windows 11 更新、所有 DPI 或多屏均已稳定。当前只保护主任务栏。
系统内部接口身份不匹配时仍停止并给出状态；该限制属于避免调用错误地址，不是 DPI 测试门禁。
Explorer 重建不自动重复注入，须重新启用；不重启 Explorer 或输入法进程。

XAML 布局尺寸依据：[FrameworkElement.ActualWidth](https://learn.microsoft.com/en-us/uwp/api/windows.ui.xaml.frameworkelement.actualwidth?view=winrt-22621)。缩放覆盖仍需真实设备测试，不能用夹具代替。
