# WindowMark 0.6.2 发布记录

发布日期：2026-10-28（用户时区 Asia/Tokyo）。用户确认「可以了没问题」，明确要求发布 GitHub，版本 0.6.2。

## 功能与范围

沿用已安装测试的 0.6.1-rc.3 功能实现，升级产品版本为 0.6.2。输入法占位保护默认关闭，轻松提示语随保护使用且可独立关闭。完整 ZIP 包含主程序、剪贴板守护、诊断工具、原生控制程序及 DLL。

新增输入法保护针对 Windows 11 主任务栏；实际系统映像身份必须匹配。Windows 10 暂不支持该新增模块，原有窗口工具不因此被关闭。高 DPI、多显示器、未来系统更新及 Explorer 重建仍保留既有适配边界，不以用户本机验收推断全部系统均兼容。
