# 单 EXE 绿色版候选验收

## 产物

- 开发目录：`WindowMark-portable`；基于 v0.6.3，分支 `feat/single-exe-portable`。
- 候选目录：`dist/rc/v0.6.4-rc.1/`，只有 `WindowMark.exe` 一个文件。
- 大小：2,790,400 字节。
- SHA-256：`B3AA4880534CAA21464D0856B7B1D36E63D9F683EBDD0E13510AD61B1A52D747`。
- 实际通过 Windows PowerShell 5.1 执行打包脚本，版本核对及产物哈希检查成功。

## 已实际执行

- Release 编译通过，核心 CTest 2/2。
- `tools/test-single-exe.py` 14 个断言通过：空目录单 EXE、配置同目录生成、五个内置组件与构建产物哈希一致、重复准备不重写、缓存缺失和损坏自动修复、中文空格路径、目录搬迁后保留提示语设置、缓存目录无法创建时返回错误且不回落 AppData。
- 最终证据：`build/evidence/single-exe-20261110-205302/result.md`。
- 将 EXE 实际释放的原生组件与既有未修改的测试宿主组合，提示语、透明模式、动态提示语开关、自动恢复四组回归全部通过：`build/evidence/single-exe-native-regression-02/summary.json`。
- 七项生命周期回归全部通过：启动等待、任务栏重建、目标进程重启、应用重开、旧目标标记清理、存活目标未确认保留偏好且不重试、旧格式标记和手动关闭。
- 真实 Explorer 的控制器锁保持原名称；自建夹具改为按目标 PID 隔离，避免占用真实保护的互斥锁。

## 保留的失败记录

首轮四组回归因旧控制器所有目标共用单例锁，受到本机正在运行的保护影响而退出（控制器 4，恢复测试 3）。未将此轮计为通过，原始证据在 `build/evidence/single-exe-native-regression/`。分离夹具互斥锁后，用重新内嵌并释放的实际组件复测通过。

## 验收边界

- 使用 `--prepare-portable` 验证单文件和配置路径，此模式不启动托盘、不附加 Explorer、不抢占运行实例。
- 原生布局测试只操作自建宿主，未强制重启用户 Explorer。
- 未替换本机正在使用的 v0.6.3。真实托盘入口、安装迁移、只读 ACL、开机启动完整验收仍待进行。
- 本轮未公开发布候选，未改动 v0.6.3 发布资产。正式发布前仍需完成双目录与公开下载核验。
