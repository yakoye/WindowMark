# 输入法左右区域坐标协作采样

本工具只读，不注入 Explorer、不修改系统设置、不截图、不操作鼠标键盘。

请将整个目录复制到本地，双击 `collect-anchors.bat`。五秒内切到本地记事本，随后约两分钟内，在本地记事本和已经连接的 RDP、VNC 或 MobaXterm 之间切换三次。请观察本机的「中」「拼」是否消失并恢复，不需要操作远程电脑内容。

将 `results` 目录放回共享目录，说明 Windows 构建号、显示缩放、显示器数量、输入法和使用的远程客户端。若无法运行，保留原始错误，不修改安全设置。

采集固定任务栏控件身份和矩形、进程文件名、环境信息；应用任务栏按钮不保存名称及路径，Everything 等托盘名称只转换为固定分类，不保存原始提示文本。不会采集输入内容、剪贴板或文档内容。

当前 Windows 11 本机已有显隐前后坐标证据；仍需要真正的 **Windows 10** 机器提供原生结构，Windows 11 结果不能替代 Win10。此工具本身不提供占位功能，未启用保护时坐标移动属于有效的原始证据，不是采集失败。

请勿运行共享目录中的早期注入实验。此次只运行本目录的只读工具。
