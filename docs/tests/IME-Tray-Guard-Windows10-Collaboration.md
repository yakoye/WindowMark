# Windows 10 原生任务栏协作测试

本轮需要真正的 Windows 10 电脑；另一台如果仍是 Windows 11，只能做 Windows 11 回归，不能替代此项。

## 运行方法

1. 将整个目录复制到 Windows 10 本地普通用户目录。无需管理员权限。
2. 双击 `collect-win10.bat`。工具为只读采集，不注入 Explorer、不修改布局、不改输入法设置、不截图。
3. 五秒内切到本地记事本，让原生「中」「拼」可见。
4. 随后两分钟内，在本地记事本和已连接的 RDP / VNC / MobaXterm 之间切换三次，使两个图标消失并恢复。不需要向远程电脑输入内容。
5. 将生成的 `results` 目录放回共享目录，并说明 Windows 版本、缩放、显示器数量、使用何种输入法、是否确实观察到两个图标消失。

采样包含任务栏结构、原生按钮标识与矩形、构建号和进程编号；不采集键盘输入、剪贴板或普通应用文档。

## 我方验收

- 核对真实构建号，Windows 10 以 build < 22000 判断，不用可能残留的 ProductName。
- 对比显隐时 HWND、Toolbar/托盘容器的宽度及兄弟位置，识别稳定的原生宿主。
- 先在相同结构的自身夹具验证固定宽度和恢复，再考虑获得授权的 Windows 10 原生原型。
- 当前主程序在 Windows 10 上只提供关闭、兼容检查和诊断入口；不会用 Windows 11 XAML 实现强行写入。
- 不运行早期独立注入试验、不重启 Explorer、不添加假图标。
