此轮只有重现，没有观测反向消失，不能判为完整往返通过。第二轮在 `WindowMark-release-065-switch-03` 继续只读采集，需观察消失和重现，并逐次比对其他托盘按钮及应用区几何。用户无需提供截图或重新登录。

## 原始失败及修正

1. 第一轮 `WindowMark-release-065-validation` 的 Explorer 重启门禁失败：新连接暂不可用，旧实现留下未确认标记后只允许复用不存在的端点。原始失败保留，不计为通过。
2. 同时发现远程前台图标隐藏时，重开的程序须等图标再次出现才能学习宽度，增加经过位置/DPI 校验的缓存。
3. 安装测试脚本未执行预期参数：Windows PowerShell 5.1 按本地编码读取无 BOM 的中文脚本，注释吞并下一行。部署脚本改为 UTF-8 BOM，保留加载器错误日志；未执行的测试不计通过。
4. 本机新版 XAML 的文件版本相同而 RSDS 标识不同。通过对应微软 PDB 核对新增精确适配，不降低未知映像门禁。
