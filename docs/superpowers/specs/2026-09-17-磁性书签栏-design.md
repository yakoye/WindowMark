# 磁性书签栏（Magnetic Dock）设计

需求来源：用户 2026-09-17 给出的完整规格（连续磁场、固定峰值、Base/Visual 分离、挤开邻居、
Directional Preview Stack、四方向统一、30 条验收项）。这份文档不重复需求本身，只记录**怎么落到
现有代码上**，以及实现过程中拍板的决定。

## 1. 现状与差距

| 现状 | 规格要求 | 处理 |
|---|---|---|
| `DrawerState::SetHovered(index)`：命中哪个标签就把它设为展开，其余收起，90ms 缓动 | 禁止离散 hover；整条栏一个连续磁场 | `DrawerState` 退出书签栏交互，换成 `MagneticDock` |
| `HitTest` 在标签间隙返回 -1 → 立即收起 | 间隙不是死区 | 磁场只看鼠标主轴坐标，不做命中 |
| 书签条是逐像素 alpha 的分层窗口，间隙像素 alpha=0 → 鼠标穿透、窗口收不到 `WM_MOUSEMOVE` | 间隙里停住也要正常计算 | 间隙画 alpha=1 的「包络带」，肉眼不可见但接得住鼠标 |
| 完整标题画在展开后的标签**内部** | 标签 / 浮动标题 / 缩略图三段独立排列 | 标签只画短名；新增独立的标题窗口 |
| 缩略图按悬停那一刻的标签矩形定位一次，450ms 后出现 | 三段跟随磁场动画实时移动、切换时 crossfade | 预览后端改成每帧更新 + 两个 DWM thumbnail 做 crossfade |
| 侧边书签挂在窗口**外面**、往外伸 | 左右与上下镜像：窗口边缘 → 书签 → 标题 → 缩略图 → 窗口内容 | 侧边改为贴窗口**内侧**、往里长，四方向共用一套几何 |

## 2. 模块划分（职责分离）

```
core（纯函数，全部单测 + 变异测试）
  MagneticDock      连续磁场 → 每个标签的 visual 尺寸与位置
  PreviewStack      标签包络 + 标题尺寸 + 缩略图尺寸 → 三段不重叠的矩形
platform/windows
  WinOverlayBackend 采集鼠标主轴坐标、推进动画帧、画标签、发出预览请求
  WinPreviewBackend 标题窗口（DirectWrite，侧边竖排）+ 缩略图窗口（DWM crossfade）
```

「磁场怎么放大」和「三段怎么排」互不知道对方：MagneticDock 的输出（标签的 visual 矩形）是
PreviewStack 的输入之一，仅此而已。

## 3. 磁场（MagneticDock）

### 3.1 坐标系

- **主轴**：Top/Bottom 为 X，Left/Right 为 Y。**交叉轴**：离开窗口边缘、伸向窗口内容的方向。
- 每个标签有固定的 **base 区间** `[b_i, b_i + m_i]`（主轴）和 **base 深度** `c_i`（交叉轴）。
  base 只由设置和标签个数决定，任何动画都不改它。
- 鼠标位置只换算成**base 空间里的主轴坐标 p**。p 只用来算距离，从不回读 visual。

### 3.2 影响力

```
d_i  = |p - (b_i + m_i/2)|                         到标签 base 中心的距离
I(d) = d < R ? 0.5 * (1 + cos(π·d/R)) : 0          余弦衰减，中心 1，R 处平滑归零
influence_i = strength · I(d_i)
```

选余弦而不是高斯：支撑区有限（R 以外严格为 0，远处标签完全不动），且在 0 和 R 两端导数都连续。
默认 R = 120px（横排节距 50px，约 2.4 个标签）。鼠标在标签中心时 I=1，恰好达到峰值；在两个标签
正中间（d=25）时两边都是 I≈0.897（高度 17→36 时约 34），对应规格里「34 / 34」的例子。

### 3.3 尺寸：峰值固定

```
main_i  = m_i + (peakMain  - m_i) · influence_i
cross_i = c_i + (peakCross - c_i) · influence_i
```

峰值是**绝对像素**，不是倍率，所以和标签自身的 base 无关：激活标签的 base 比别人大，但被吸到
峰值时和别人一样高。这保证鼠标从普通标签滑到激活标签时峰值不跳。若某个 base 大于峰值，峰值按
该 base 取（只放大、不缩小）。

### 3.4 主轴排布：以鼠标为不动点挤开邻居

visual 排布从鼠标所在点向两侧展开，**鼠标下方的那个点始终留在鼠标下方**：

- 鼠标在标签 k 内：`f = (p - b_k) / m_k`，`V_k = p - f · main_k`，其余标签按 `main + gap` 向两侧依次排开。
- 鼠标在 k 与 k+1 的间隙内：`q = p - (b_k + m_k)`，`V_k = p - q - main_k`，`V_{k+1} = p + (gap - q)`。
- 鼠标在首个标签之前 / 末个之后：整条栏只向另一侧展开。

p 穿过标签边界时 f→1 与 q→0 两个公式给出同一个位置，所以位置对 p 连续；尺寸本身也对 p 连续，
于是整条栏的每个像素都随鼠标连续运动。间隙不缩放，保持 `gap`。

这样还顺带保证了规格里的两件事：鼠标不会「追着标签跑」（不动点）；base 命中与 visual 命中一致
（鼠标所在的 base 标签就是它看到的那个标签），所以点击判定可以直接用 base。

### 3.5 时间维度

- **磁场强度 strength**：进入整条栏时目标为 1，离开（含 60ms 宽限）后目标为 0，指数逼近，
  时间常数 = `drawer.animation_ms / 3`（默认 90ms → 约 90ms 内走完 95%）。这是「不允许突然放大/
  缩小」的唯一来源；鼠标在栏内移动时 strength 恒为 1，磁场即时跟随鼠标，没有追踪动画。
- **视觉值轻微平滑**：每个标签的 main/cross 以 τ=16ms 指数逼近目标（约一帧）。所有标签用同一个
  τ、同一帧统一推进，没有各自独立的动画。
- 帧驱动：`WM_MOUSEMOVE` 立即重算重绘一次（不等定时器）；16ms 定时器只在 strength 或平滑值
  尚未收敛时运行，收敛后停掉。

### 3.6 离开宽限

`WM_MOUSELEAVE` 不立刻生效，启动 60ms 宽限计时；期间回到栏内就取消。宽限只用于「离开整条栏」，
标签之间不存在离开——间隙本来就在栏内（见 §5.2 包络带）。

### 3.7 主标签（primary）

influence 最大的标签。为避免鼠标停在两标签正中间小幅抖动时来回切换，新候选必须比当前 primary
的 influence 高出 0.02 才切换。primary 只决定标题和缩略图显示谁，不影响标签尺寸。

## 4. 三段式预览栈（PreviewStack）

### 4.1 统一规则

输入：方向、工作区、栏的根边位置、标签 visual 矩形列表、主标签中心（主轴）、标题尺寸、缩略图
尺寸、两个间距。输出：标题矩形、缩略图矩形、缩略图是否放得下。

```
交叉轴（从窗口边缘往窗口内容）：
  titleStart = 根边 + 标题主轴跨度内所有标签 visual 深度的最大值 + bookmarkToTitleGap
  thumbStart = max(titleEnd + titleToThumbnailGap,
                   根边 + 缩略图主轴跨度内所有标签深度最大值 + bookmarkToTitleGap)
主轴：以主标签 visual 中心为中心，夹进工作区
```

「跨度内所有标签的最大深度」而不是「主标签的深度」：标题比标签宽，会压到邻居头上；取最大值才
能保证任何时刻都不和任何标签重叠。最大值对各标签深度连续，所以位置仍然连续。

方向只决定两个符号：交叉轴往哪边长（Bottom 向上、Top 向下、Left 向右、Right 向左）和主轴是哪根轴。
四个方向共用同一个函数，Top/Bottom、Left/Right 天然镜像。

### 4.2 主标签切换时

标题和缩略图的**位置**在 crossfade 时长内从旧主标签中心平滑移到新主标签中心；**内容**同时
crossfade（旧的淡出、新的淡入）。不出现空白帧。时长 `preview.crossfade_ms`，默认 100ms。

### 4.3 标题

- Top/Bottom 横排；Left/Right 竖排（DirectWrite `DWRITE_READING_DIRECTION_TOP_TO_BOTTOM`，真正的
  竖排排版：中文字形直立，拉丁字母按竖排规则侧转）。
- **左右两侧都从上往下读**。规格里给 Right 的建议是「vertical-rl + 180°」，但同一条又要求两侧都
  「自然从上到下阅读」，而旋转 180° 会让右侧变成从下往上读。按规格「最终以视觉可读性为准」，
  两侧都用从上往下；镜像体现在排列顺序和贴边方向上。
- 超长标题：主轴方向限长（横排不超过缩略图宽度，竖排不超过缩略图高度），用 DirectWrite 的省略号
  裁剪，不换行，保证三段结构不被撑坏。
- 标题有浅色圆角底，否则压在任意窗口内容上读不清。

### 4.4 缩略图

- 仍是 DWM thumbnail。切换源窗口时同时注册新旧两个 thumbnail，按 crossfade 进度调 opacity，
  结束后注销旧的。
- 首次出现仍受 `preview.delay_ms` 控制（默认 450ms），避免鼠标一扫而过时缩略图乱闪；出现后跟随
  主标签连续切换，不再等待。标题不等待，随磁场立即出现。
- 交叉轴放不下（窗口太靠近屏幕另一侧）时，缩略图按比例缩小到放得下；小于 120×80 就不显示，
  绝不压到标题或标签上。
- 书签指向宿主窗口自己时不显示缩略图（和现在一样），只显示标题。

## 5. 平台层（WinOverlayBackend）

### 5.1 窗口几何

- 所有方向：书签条贴在宿主窗口**内侧**的对应边缘，标签从边缘往窗口内长。侧边不再挂在窗口外。
- 窗口在交叉轴上的厚度 = 峰值深度；主轴长度 = base 总长 + 两侧各留「最大可能挤开量」。
  最大挤开量在 core 里按鼠标位置扫一遍取最大值（`MaxGrowth`），不是估计。多出来的区域完全透明、
  鼠标穿透，不影响宿主窗口。
- base 总长在主轴上居中于宿主（横排）或从 `drawer.top_offset` 开始（侧边，沿用现有设置）。
- 被工作区夹住时，visual 排布整体平移回窗口内（只在屏幕边缘发生，破坏不动点可以接受）。

### 5.2 包络带

每帧在标签之间的间隙里画 alpha=1/255 的矩形，深度取两侧标签 visual 深度的较小值；栏两端不画。
这样鼠标沿栏水平移动、即使穿过间隙，也始终在窗口的可命中像素上，`WM_MOUSELEAVE` 只在真正离开
栏的外轮廓时才发生。1/255 的亮度差人眼不可见。

### 5.3 标签内容

标签内只画短名（`drawer.short_name_chars`），字号跟随 visual 交叉深度。完整名字只出现在浮动标题里。

## 6. 设置

新增（格式与现有 `drawer.*` / `drawer.bottom_*` 的分工一致：侧边与横排各一套）：

| 键 | 默认 | 含义 |
|---|---|---|
| `drawer.bottom_magnet_max_extent` | 72 | 横排：峰值时标签宽度（主轴） |
| `drawer.bottom_magnet_max_thickness` | 36 | 横排：峰值时标签高度（交叉轴） |
| `drawer.magnet_max_extent` | 56 | 侧边：峰值时标签伸入窗口的深度（交叉轴） |
| `drawer.magnet_max_thickness` | 52 | 侧边：峰值时标签高度（主轴） |
| `drawer.magnet_radius` | 120 | 磁场半径，px，主轴方向 |
| `drawer.magnet_grace_ms` | 60 | 离开整条栏的宽限 |
| `preview.title_gap` | 7 | 标签 → 标题 |
| `preview.thumbnail_gap` | 10 | 标题 → 缩略图 |
| `preview.crossfade_ms` | 100 | 主标签切换时的交叉淡入淡出 |

**退役**：`drawer.expanded_extent`、`drawer.bottom_expanded_extent`。它们定义的是「悬停后把整个
名字塞进标签的展开宽度」，磁性栏里这个状态不存在了。配置文件里保留读写（不报错、不丢值），但不再
生效，设置对话框里由峰值设置取代。README「定过的数值」表同步标注，不静默删除。

沿用：`bottom_collapsed_extent`（横排 base 宽）、`bottom_collapsed_thickness` / `thickness`（横排
base 高）、`bottom_active_thickness`（激活标签 base 高）、`thickness`（侧边 base 高）、
`collapsed_extent`（侧边 base 深度）、`active_extra_extent`、`gap`、`animation_ms`、`top_offset`。

## 7. 测试

### 7.1 core 单元测试（对应规格验收项）

- 峰值：鼠标在任一标签中心时该标签 main/cross 精确等于峰值；激活与非激活标签峰值相同。
- 连续性：鼠标以 0.25px 步长从栏外扫到栏外，每一步每个标签的尺寸、位置变化都不超过由 R 和峰值
  推出的上界（没有跳变）；覆盖首尾、间隙正中、方向突变（来回扫）。
- 间隙：鼠标在间隙正中，两侧标签 influence 相等且 > 0.9，不存在全部为 0 的位置。
- 不动点：鼠标所在点在 visual 中仍在鼠标下；visual 区间单调、互不重叠、间距恒为 gap。
- Base/Visual 分离：同一 p 反复计算结果相同（无反馈）；base 在任意 p 下不变。
- 远处不受影响：距离 ≥ R 的标签严格保持 base。
- 主标签滞回：在两标签中点 ±0.5px 抖动不切换。
- PreviewStack：四方向下三段两两不重叠、与所有标签矩形不重叠、Top/Bottom 与 Left/Right 严格镜像、
  主轴夹进工作区、交叉轴放不下时缩小或隐藏但不重叠、标签长高时标题和缩略图同步外移且间距不变。

每个纯函数配变异测试，确认上面的断言真的抓得住错。

### 7.2 需要实机确认的

「像手指滑过钢琴键」是手感，单测只能保证没有跳变，是否丝滑要人来看。四个方向、激活与悬停不同、
离开再回来、长标题、屏幕边缘，都在实机上逐项走一遍。
