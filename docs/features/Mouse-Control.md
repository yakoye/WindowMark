# 鼠标控制

适用于 WindowMark 0.6.5。独立于窗口拖动、窗口书签、输入法占位等模块，无需安装 AutoHotkey。

## 使用

托盘右键 → 鼠标控制：

- 滚轮调节：点击启用/关闭。
- 指针调节：点击启用/关闭。
- 鼠标设置…：在一个面板中调整两项参数，也可分别开关。

两项默认关闭。子项启用时对应打勾，任意子项实际运行时父级鼠标控制打勾。主面板提供鼠标控制按钮。

滚轮默认 50 毫秒，觉得快可用 80 或 100；可设 1–1000。上下左右四个方向各自计时，首次及方向切换立即响应；持续滚动只以已放行时间为基准，避免全部被吞掉。每次放行规范化为一格，累计的高频输入不排队补发。垂直滚轮、水平滚轮都处理；Ctrl、Shift 状态保持原样。因此启用时也会影响 Ctrl+滚轮缩放。此设置作用于当前桌面可监听的全部滚轮，不按硬件或 ToDesk 进程区分。

指针速度范围 1–20，10 为预设值。它调整 Windows 原生指针速度，可能同时影响本地鼠标。ToDesk 如果直接发送绝对坐标，指针移动可能不经过 Windows 速度设置，需要手机实测；不承诺改变远程端的绝对坐标映射。

## 保存与恢复

配置保存在主 EXE 同目录的 settings.conf：

```ini
mouse.wheel_enabled=false
mouse.wheel_interval_ms=50
mouse.pointer_enabled=false
mouse.pointer_speed=10
```

参数保存后立即生效，两个开关互不依赖。开启指针调节前，程序将原速度和应用速度原子记录到同目录 mouse-speed.restore；关闭或正常退出时恢复原值。异常退出时该记录留到下次启动恢复。若系统速度已被用户或别的软件改过，恢复时不覆盖新的值。无法读取有效恢复记录会显示错误，保留原件，不猜测原速度。

滚轮钩子运行于独立消息线程，避免设置面板阻塞主线程导致钩子超时。处理第三方模拟输入，仅跳过本模块标记的重发事件；重发失败时放行原始事件。受保护桌面、权限较高应用或远程工具绕过普通输入链的情况，不能仅凭核心测试保证拦截有效。无需修改系统滚动行数或全局输入法配置。
