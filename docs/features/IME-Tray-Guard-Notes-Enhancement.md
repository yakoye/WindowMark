# 后续增强：留位小纸条

2026-10-24，与用户讨论确定方向；本文件是后续设想，不表示已经实现。

## 前置条件

原生占位稳定、原生点击正常、恢复可靠。任何装饰内容都不得参与宽度计算或扩大输入法原有槽位。
先完成 Windows 10/11 分别验收，再把可选显示与布局保护解耦实现。

## 推荐方案

- 默认纯留白，用户可选“短句小纸条”。原生图标消失才出现；回来时完全让回原生显示与点击。
- 优先 2～4 个汉字：喝口水、眨眨眼、松松肩、慢慢来、稳住呀、歇一下、加油鸭、别卷啦、摸鱼中。
- emoji 可选并实际测量字形宽度，不能靠字符数判定能否放下；“放松一下😌”缩为“放松😌”。
- 同一次隐藏期间不轮播、不滚动、不闪烁；用户点击才换一句。需要完整解释时放在悬停提示中。
- 其他候选：远程状态、可确认的本机输入法名称、用户启动的小计时、自定义短句。
- 输入法名称不能冒充远程电脑状态；只有上次信息时标明“上次”。对应设置仅在可靠入口存在时提供。

## 明确不做

不强制提醒、不推送广告、不采集用户输入、不新增假输入法托盘图标、不逐个锁死别的图标。
不把此设想塞入尚未完成稳定性验收的 0.6.1-rc.1。
