# 输入法占位保护：主程序集成与验收清单

更新：2026-11-10。0.6.3 修复配置保留和 Explorer 重启恢复，历史验证范围独立保留。

## 集成约定

- 主面板和托盘使用相同命令分发，不再打开独立预览程序。
- `ime_guard.enabled=false` 为默认值。窗口工具总开关不改变此功能。
- 勾选表示用户已保存的启用偏好；状态文字独立显示实际生效、恢复中、未确认恢复。只有显式关闭改变偏好。
- 启用前说明限定映像的非公开布局接口，确认框归属于当前主面板。rc.3 开放 Windows 11 各种缩放和多屏测试，不以补丁号为门禁；实际加载映像仍必须匹配已核对的内部接口。
- UI 线程 250ms 续租；界面失联 2 秒、目标失联 3 秒停止续租；目标端有限期限负责恢复。
- 显示变化先恢复，稳定 2 秒后重新学习；锁屏/断开/休眠时暂停，恢复会话后自动重连。Explorer 重建或进程变化后自动恢复，开机等待就绪。手动关闭取消重连；同一存活目标恢复未确认时保留偏好并暂停。
- 提示语独立显示开关；只有已占位且原生图标缺席时才显示。XAML 原生文字随缩放布局，IsHitTestVisible=false；文字失败不停止宽度保护。
- 正常关闭恢复并确认写入/恢复次数相同；标记记录目标 PID 和创建时间。旧进程死亡后标记失效，同一存活进程的未确认标记阻止自动重试但不清配置。
- 原生 DLL 从独立运行副本加载，安装目录不被 Explorer 锁定。不强制卸载 Explorer 内的诊断 DLL，不重启 Explorer。

## 验收顺序

1. 核心配置/状态判据测试和原有回归。
2. 自身 XAML 夹具上的持续租约、UI 失联、控制进程退出；禁止并行争抢全局控制器锁。
3. 主程序默认关闭启动，不连接 Explorer；主面板和托盘可操作。
4. 当前已获授权的本机上手动启用，haps03 与本地切换；记录原生按钮坐标、Explorer PID、写入与恢复数。
5. 主程序恢复、关闭、再次启动的配置一致性；仅在用户已启用时自动恢复，默认关闭及手动关闭后不自启。
6. Windows 10 只读采样先行；其 HWND/Toolbar 结构不可套用 Windows 11 XAML 容器。

## 未解决的风险

rc.2 已删除 `AdviseVisualTreeChange` 调用，通过限定映像的局部根接口读取当前线程的 Island，移除已知的跨线程全根回放路径。旧转储缺少对象堆，仍不能还原具体失败对象的类型；不能把路径移除写成已经还原全部系统内部根因。

新路径依赖私有 C++ ABI；同时校验已加载映像的 PDB GUID/age、映像大小及函数入口字节，不匹配即拒绝，不回退旧订阅。0.6.3 已修复配置保留及重启恢复并完成对应测试，系统更新、多屏/DPI 等适配仍需独立验收，见版本测试记录。

## 0.6.5 旧标记自动恢复

旧标记不再导致永久暂停。自动控制会话附带 --reuse-only，只接回当前 Explorer 内既有的 LocalRoots07 端点；没有端点时禁止首次附加，端点忙碌时不抢占。已有端点本身只在旧租约已释放且恢复成功时接受下一租约，因此兼容旧 DLL，不需要重启 Explorer。暂时失败按 5、15、30 秒退避，手动关闭取消等待，已知恢复失败停止并显示原因。托盘父级的勾选代表实际生效，保存的偏好独立显示。夹具回归及实机证据见 [自动恢复测试](../tests/IME-Automatic-Recovery-20261124.md)。

## 宽度缓存与 Explorer 就绪等待

主程序在原生占位实际生效后，将宽度、任务栏 DPI 和完整屏幕矩形原子写入同目录 `ImeTrayGuard/width-cache.conf`。重开时即使原生输入法图标正被远程应用隐藏，也可在完全相同的布局下恢复该宽度。DPI、任务栏矩形不匹配或缓存损坏时拒绝使用，等待原生图标显现后重新学习；首次使用仍需显示原生图标一次。

控制协议升级为 4，尾部追加宽度上下文；只读查询端点协议后兼容旧版 3 的固定前缀。旧端点继续可复用，但不读取新缓存字段。新 Explorer 中的诊断连接全部返回 `ERROR_NOT_FOUND` 时，只有完整模块枚举确认原生组件未加载，才返回“从未附加”的专用结果并延迟重试。枚举失败、组件已加载、已有端点忙碌或恢复失败均不归入此分支。

新增精确映像使用微软 PDB 的 `Diagnostics::DiagnosticsInterop::GetXamlIslandRoots` 符号核对，仍须同时匹配映像大小、完整 RSDS GUID/age 和函数前缀，不按文件版本猜测、不扫描地址兜底。参考 [微软符号说明](https://learn.microsoft.com/en-us/windows/desktop/dxtecharts/debugging-with-symbols)和 [XAML 诊断入口](https://learn.microsoft.com/en-us/windows/win32/api/xamlom/nf-xamlom-initializexamldiagnosticsex)。
