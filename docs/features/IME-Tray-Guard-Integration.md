# 输入法占位保护：主程序集成与验收清单

更新：2026-10-25。本文记录开发进度，不是稳定发布声明。

## 集成约定

- 主面板和托盘使用相同命令分发，不再打开独立预览程序。
- `ime_guard.enabled=false` 为默认值。窗口工具总开关不改变此功能。
- 用户请求、实际生效、恢复中、未确认恢复分别显示；只有控制程序存活、目标采样新鲜且原生状态为 Reserved 才打勾。
- 启用前说明限定映像的非公开布局接口，确认框归属于当前主面板。rc.3 开放 Windows 11 各种缩放和多屏测试，不以补丁号为门禁；实际加载映像仍必须匹配已核对的内部接口。
- UI 线程 250ms 续租；界面失联 2 秒、目标失联 3 秒停止续租；目标端有限期限负责恢复。
- 显示变化先恢复，稳定 2 秒后重新学习；锁屏/断开/休眠时暂停，恢复会话后自动重连一次。手动关闭取消重连；恢复未确认、Explorer 重建或连接失败停止，不循环附加。
- 提示语独立显示开关；只有已占位且原生图标缺席时才显示。XAML 原生文字随缩放布局，IsHitTestVisible=false；文字失败不停止宽度保护。
- 正常关闭恢复并确认写入/恢复次数相同；异常标记未清除时禁止下次自动启用。
- 原生 DLL 从独立运行副本加载，安装目录不被 Explorer 锁定。不强制卸载 Explorer 内的诊断 DLL，不重启 Explorer。

## 验收顺序

1. 核心配置/状态判据测试和原有回归。
2. 自身 XAML 夹具上的持续租约、UI 失联、控制进程退出；禁止并行争抢全局控制器锁。
3. 主程序默认关闭启动，不连接 Explorer；主面板和托盘可操作。
4. 当前已获授权的本机上手动启用，haps03 与本地切换；记录原生按钮坐标、Explorer PID、写入与恢复数。
5. 主程序恢复、关闭、再次启动的配置一致性；异常后不自动开启。
6. Windows 10 只读采样先行；其 HWND/Toolbar 结构不可套用 Windows 11 XAML 容器。

## 未解决的风险

rc.2 已删除 `AdviseVisualTreeChange` 调用，通过限定映像的局部根接口读取当前线程的 Island，移除已知的跨线程全根回放路径。旧转储缺少对象堆，仍不能还原具体失败对象的类型；不能把路径移除写成已经还原全部系统内部根因。

新路径依赖私有 C++ ABI；同时校验已加载映像的 PDB GUID/age、映像大小及函数入口字节，不匹配即拒绝，不回退旧订阅。系统更新、Explorer 自然重建、多屏/DPI 和长期运行仍需要独立验收；本次不发布。
