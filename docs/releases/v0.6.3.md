# WindowMark v0.6.3

修复「任务栏输入法占位保护」启用后，在重开程序、重启电脑或 Explorer 重建后丢失开关设置的问题。

- 用户启用偏好与保护运行状态分开：暂时停止不再把配置保存为关闭。
- 开机等待任务栏就绪，Explorer 重建后自动重新连接并学习宽度。
- 恢复标记增加目标进程身份，清理属于已退出进程的标记，同时兼容旧版标记。
- 托盘和主面板的勾选代表已保存的启用设置，状态文字说明是否实际生效。
- 同一存活 Explorer 的恢复结果未确认时保留设置并暂停，不无限循环附加；手动关闭会取消自动恢复。

完整解压 `WindowMark-v0.6.3-win64.zip` 后运行 `WindowMark.exe`，保留 `tools` 目录。旧版已经误保存为关闭的用户，升级后重新勾选一次即可。也可在退出程序后使用 `WindowMark.exe --ime-guard-enable` 显式开启。

新增生命周期回归覆盖启动等待、任务栏重建、测试宿主进程退出、应用重开和新旧恢复标记。未通过重启用户整台电脑或强制重启日常 Explorer 冒充真机验收；输入法保护的 Windows 11 内部接口适配范围与上版相同。

验证完成：核心测试 2/2、Python 52/52、新增生命周期七项、原有四组回归全部通过。本机安装后，正常退出并不带参数重开 WindowMark，已自动恢复 140 DIP 占位及提示语设置。
