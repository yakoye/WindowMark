# WindowMark v0.6.2

新增任务栏输入法占位保护：Windows 原生「中」「拼」消失后保留原有空间，减少相邻托盘图标的位置变化。功能独立、默认关闭，可从主面板或托盘启用，也可一键恢复系统布局。

- 空位可显示「加油鸭」「喝杯水」「歇一会」等六条轻松提示语，每 45 秒轮换；原生图标恢复时隐藏，提示语不拦截点击，可单独关闭。
- 显示布局变化及会话恢复后重新学习宽度；异常恢复未确认时停止，不反复重启 Explorer 或输入法。
- 新增窗口书签拖动分组、抓取窗口分组和数字快捷键，修正剪贴板守护状态显示。
- 已完成用户本机试用确认；八小时监测 5711 次采样，未记录到进程缺失、保护失效、日志过期或错误。Release 构建、核心测试及相关自动化回归通过。

## 下载与运行

下载 `WindowMark-v0.6.2-win64.zip`，完整解压后运行 `WindowMark.exe`。请保留 `tools` 目录，其中包含输入法保护的必要组件；不要只复制主 EXE。需要安装时，在托盘菜单选择「安装到系统」。

## 支持范围

新增输入法保护当前针对匹配系统内部接口的 Windows 11 主任务栏。Windows 10 的此项功能尚未适配，不影响原有窗口工具；高 DPI、多屏及未来 Windows 更新仍需进一步验证。系统组件不匹配时会拒绝修改布局并显示原因。

历史候选、失败证据及已验证范围保留在仓库测试文档中。本版本不提供缺少控制程序和 DLL 的单文件替代包。
